# Nebius AI Cloud documentation

> Nebius AI Cloud is a cloud platform built for AI workloads: GPU compute and InfiniBand clusters, managed Kubernetes and Slurm, object storage, networking, inference and other AI services.
> This file maps its documentation at docs.nebius.com for coding and research agents.
> Read the operating instructions directly below first — they explain how to search the corpus, fetch any page as raw Markdown, and drive the `nebius` CLI — then use the link map that follows.

## Working with these docs as an agent

Every documentation page is available as raw Markdown: take any `https://docs.nebius.com/...` page URL and append `.md` (for example `https://docs.nebius.com/compute/quickstart.md`).
Fetch the `.md` form, never the rendered HTML.

### Search and read the docs over MCP (no install, no auth)

The docs ship a Mintlify MCP server at `https://docs.nebius.com/mcp`.
It is stateless JSON-RPC over HTTP `POST` — no `initialize`, no session, no key.
Call it straight from a shell.
`Accept` must include `text/event-stream`; results arrive as SSE `data:` lines, and the text sits at `result.content[].text`.

Two read tools:

- `search_nebius_ai_cloud` — arg `query` (natural language).
  Ranked hits with title, link, and section path.
  Use this when you do not know the exact page.
- `query_docs_filesystem_nebius_ai_cloud` — arg `command`.
  A read-only shell (`ls find cat head grep -n sed -n awk` and pipes) over an in-memory mirror of the whole site rooted at `/`.
  Use absolute paths; no working directory persists between calls.
  Use this to locate a literal, then slice exact lines.

```bash
curl -sS https://docs.nebius.com/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search_nebius_ai_cloud","arguments":{"query":"create a GPU cluster with InfiniBand"}}}' \
  | sed -n 's/^data: //p' | python3 -c 'import sys,json
[print(c["text"]) for l in sys.stdin for c in json.loads(l).get("result",{}).get("content",[])]'
```

Swap `name`/`arguments` for the filesystem tool, e.g. `{"name":"query_docs_filesystem_nebius_ai_cloud","arguments":{"command":"grep -rln \"security group\" /vpc"}}`.

### Nebius CLI

The CLI binary is `nebius`.
Its command reference is machine-generated and self-documenting, so **discover commands and flags by running them**, not by reading reference pages:

```bash
nebius --help                                  # top-level services
nebius compute --help                          # a service's resources
nebius compute instance create --help          # a command's flags
```

Read the CLI *guides* for concepts and setup — install, configure, quickstart, interactive mode, JSONPath output, exit codes (linked in the map below).
Skip the per-command reference tree; `--help` is faster and always accurate to the installed binary.

### REST API

Every service is reachable over REST at `https://api.nebius.cloud`; read the OpenAPI spec at https://api.nebius.cloud/openapi.json.
Use a Bearer token to authorize requests.
Get an access token with `nebius iam get-access-token`.
